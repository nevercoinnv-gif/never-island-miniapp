# Never Island — Miniapp

این مخزن شامل یک صفحهٔ استاتیک واکنش‌گرا با طراحی کلی برای بازی/مینی‌اپ "Never Island" است.

برای اجرای محلی:

```bash
# نصب وابستگی‌ها
npm install

# حالت توسعه (Vite)
npm run dev

# ساخت برای تولید
npm run build

# پیش‌نمایش نسخهٔ build
npm run preview
```

توضیحات کوتاه:
- فایل اصلی: `index.html`
- کد تعاملی: `src/app.js`

اگر می‌خواهید من راه‌اندازی CI/CD یا انتشار را هم اضافه کنم بگویید (مثلاً GitHub Pages یا Netlify).
